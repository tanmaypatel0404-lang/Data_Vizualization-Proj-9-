# 📊 Pandas Analyzer & Data Visualization

### 🚀 Turning Raw Sales Data into Meaningful Insights

A Python-based data analysis project that transforms raw sales records into useful insights through data cleaning, statistical analysis, and interactive visualizations using Pandas, NumPy, Matplotlib, and Seaborn.

---

## 🌟 About the Project

**Pandas Analyzer & Data Visualization** is a beginner-friendly Python project developed to explore, analyze, and visualize sales data efficiently. It demonstrates how data analysis libraries can be used to organize raw information, identify patterns, calculate important statistics, and present results through clear and informative charts.

The project is implemented in **Jupyter Notebook**, with code organized into multiple smaller cells for easier execution, understanding, and testing.

The project includes a CSV dataset containing **120 sample sales records**, with details about products, sales dates, regions, quantities, prices, and profits.

## 🎯 Project Objectives

- 📂 Load sales data from a CSV file.
- 🧹 Clean data by handling missing values and removing duplicates.
- 🔍 Explore, search, sort, and filter sales records.
- 🔢 Perform numerical calculations using NumPy.
- 📈 Calculate statistical measures and summarize sales performance.
- 🔗 Combine and manipulate DataFrames using different Pandas operations.
- 📊 Create meaningful visualizations to understand sales trends and comparisons.
- 💾 Save filtered records and charts for future reference.

## 📉 Visualizations Included

The project supports several types of visualizations:

- 📊 **Bar Chart:** Compare total sales across regions.
- 📈 **Line Chart:** Explore sales patterns over time.
- 🔵 **Scatter Plot:** Examine the relationship between quantity and sales.
- 🥧 **Pie Chart:** Display each region's share of total sales.
- 📉 **Histogram:** Understand the distribution of sales values.
- 📦 **Box Plot:** Compare sales distributions across regions.
- 🔥 **Correlation Heatmap:** Examine relationships between numerical variables.
- 🖼️ **Subplots:** Display multiple visualizations in a single figure.

## ⚙️ Installation and Setup

### Step 1: Download the Project

Clone your GitHub repository or download it as a ZIP file and extract it.

```bash
git clone <your-repository-url>
```

Replace `<your-repository-url>` with your actual GitHub repository URL.

### Step 2: Install the Required Libraries

Open a terminal and run:

```bash
python -m pip install pandas numpy matplotlib seaborn jupyter
```

### Step 3: Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `Pandas_Analyzer_Full_Working.ipynb` in your browser.

### Step 4: Run the Project

Execute the notebook cells in order using **Shift + Enter**. If prompted, enter a product name or region to explore the dataset.

Example product names: `Laptop`, `Phone`, `Tablet`

Example regions: `North`, `South`, `East`, `West`, `Central`
